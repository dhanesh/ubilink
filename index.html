Ubilink

Copy a link to whatever you're looking at, from the menu bar. Link two things together, and each one remembers the other.

Download for Mac
brew install --cask dhanesh/tap/ubilink

Free and open source · macOS 10.15 or later · Apple silicon and Intel

What it does

Capture ⌘⇧K

Copies a link to the page, file, note or task in front of you, ready to paste anywhere.

Link two things

Connect a doc to the ticket it answers, or a note to its source. Each side shows the other as a backlink.

Browse ⌘⇧L

Find a link you made, then open it or copy it again. The panel opens over any app and closes with Esc.

Native and light

A native Mac app with no web view. It uses the system font, follows your accent colour and light or dark mode, and stays out of the way in the menu bar.

Install

Homebrew

brew install --cask dhanesh/tap/ubilink

Update with brew upgrade --cask ubilink.

Download

Open the DMG and drag Ubilink to Applications. Each release is signed and notarized by Apple, and comes with a SHA256SUMS file:

shasum -a 256 -c SHA256SUMS

First run

macOS asks once for Automation permission, so Ubilink can read the page or file in the app you're using. You can turn on Open at Login in Settings (⌘⇧,).

Private by design

Your links live in a database on your Mac. Ubilink doesn't sign you in, sync, or send anything over the network.

Export your whole graph to a JSON file whenever you like, and import it back on another Mac.

Links open without a shell. Dangerous link types are refused, and apps or installers are shown in Finder instead of run.
