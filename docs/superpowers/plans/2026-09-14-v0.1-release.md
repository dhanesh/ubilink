# Ubilink v0.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Ubilink v0.1.0 as a Developer ID–signed, notarized, universal macOS DMG from a gated GitHub Actions pipeline, with one version source and honest release docs.

**Architecture:** Small, testable shell scripts own each decision (`version.sh`, `check-version.sh`, `release-mode.sh`, `changelog-section.sh`); `scripts/bundle-macos.sh` does the packaging using only Apple tools (`lipo`, `codesign`, `hdiutil`, `notarytool`, `stapler`) in three modes; `release.yml` wires them into least-privilege jobs that end in a *draft* release.

**Tech Stack:** Bash (macOS `/bin/bash` 3.2-compatible where run locally; CI uses the runner's bash), GNU Make, Rust 1.92.0 / Tauri 2, GitHub Actions (macOS + Ubuntu runners), `gh` CLI.

**Spec:** `docs/superpowers/specs/2026-09-14-v0.1-release-design.md` (read it alongside this plan).

## Global Constraints

- Rust toolchain stays pinned at `1.92.0` (`rust-toolchain.toml`); **no new crates**.
- **No new third-party GitHub Actions.** Every `uses:` stays pinned to a full commit SHA with a version comment (existing pins: `actions/checkout@11d5960a326750d5838078e36cf38b85af677262 # v4.4.0`, `dtolnay/rust-toolchain@02cb101ec7c40f2c49e1d9714d64511d8e1b74de # master @ 2026-09-12`, `Swatinem/rust-cache@6323deb102c322ba6fcbdcafc7e3dddab59af2b6 # v2.9.2`, `actions/setup-node@49933ea5288caeca8642d1e84afbd3f7d6820020 # v4.4.0`, `actions/upload-artifact@ea165f8d65b6e75b540449e92b4886f43607fa02 # v4.6.2`). Artifacts are downloaded with the preinstalled `gh run download`, not a new action.
- Version source of truth: `desktop/Cargo.toml` `[package] version`. Target version: **`0.1.0`**.
- Bundle identifier `org.dhanesh.ubilink` (unchanged); product/bundle name `Ubilink`; executable `ubilink`; `LSMinimumSystemVersion` `10.15`.
- The only entitlement is `com.apple.security.automation.apple-events` = true.
- Apple credential variables (all six or none): `APPLE_SIGNING_IDENTITY`, `APPLE_CERTIFICATE_P12_BASE64`, `APPLE_CERTIFICATE_PASSWORD`, `APPLE_API_KEY_ID`, `APPLE_API_ISSUER`, `APPLE_API_KEY_P8_BASE64`.
- A final tag (`vX.Y.Z`) must **fail** without credentials; an rc tag (`vX.Y.Z-rc.N`) or a manual run may produce `Ubilink-<ver>-universal-UNNOTARIZED.dmg`.
- Releases are created as **drafts** only; only the `draft-release` job has `contents: write`.
- `make verify LOCKED=--locked` must pass at the end of every task.
- **Permission guard:** in auto / bypass permission modes the repo's PreToolUse hook *denies* edits to any `.github/**`, any `Makefile` and `.claude/settings*.json` (PR #15). Tasks 1, 2, 3, 4, 5 and 7 edit those paths — run them in **default** permission mode so the edits prompt instead of being refused.
- Commit messages end with the session attribution lines; one PR per task (or per the executing workflow's grouping), each green on CI before merge.

# Tests for scripts/version.sh and scripts/check-version.sh (run by `make test-scripts`).
set -uo pipefail
HERE="$(cd "$(dirname "$0")" && pwd)"
pass=0

# mk DIR DESKTOP_VER CORE_VER REGISTRY_VER CHANGELOG_VER TAURI_SETS_VERSION(yes|no)
mk() {
  mkdir -p "$1/desktop" "$1/src-tauri" "$1/registry"
  printf '[package]\nname = "d"\nversion = "%s"\n\n[dependencies]\ntauri = { version = "2" }\n' "$2" >"$1/desktop/Cargo.toml"
  printf '[package]\nname = "c"\nversion = "%s"\n' "$3" >"$1/src-tauri/Cargo.toml"
  printf '[package]\nname = "r"\nversion = "%s"\n' "$4" >"$1/registry/Cargo.toml"

# expect NAME WANT_EXIT DIR [STDERR_SUBSTRING]

    pass=$((pass + 1))
  else

}

T="$(mktemp -d)"
trap 'rm -rf "$T"' EXIT

expect "all agree" 0 "$T/ok"

# Print a crate's [package] version. The app's version — desktop/Cargo.toml — is the

- [ ] **Step 4: Write `scripts/check-version.sh`**

```bash
#!/usr/bin/env bash
# Fail when anything disagrees with the app version (desktop/Cargo.toml):
# the core and registry crates, a stray "version" in desktop/tauri.conf.json (Tauri
# must read Cargo), or a CHANGELOG.md with no section for it (release notes come
# from that section). Part of `make verify`.
#   check-version.sh [ROOT]
set -euo pipefail
HERE="$(cd "$(dirname "$0")" && pwd)"
ROOT="${1:-$(cd "$HERE/.." && pwd)}"
v="$(bash "$HERE/version.sh" "$ROOT")"
fail=0
for toml in src-tauri/Cargo.toml registry/Cargo.toml; do
  got="$(bash "$HERE/version.sh" "$ROOT" "$toml")"
  if [ "$got" != "$v" ]; then
    echo "check-version: $toml is $got, expected $v (from desktop/Cargo.toml)" >&2
    fail=1
  fi
done
if grep -q '"version"' "$ROOT/desktop/tauri.conf.json"; then
  echo "check-version: desktop/tauri.conf.json must not set \"version\" (Tauri reads desktop/Cargo.toml)" >&2
  fail=1
fi
if ! grep -qF "## [$v]" "$ROOT/CHANGELOG.md" 2>/dev/null; then
  echo "check-version: CHANGELOG.md has no '## [$v]' section" >&2
  fail=1
fi
exit "$fail"
```

#!/usr/bin/env bash
# Tests for scripts/release-mode.sh: how a build picks its signing mode, and the
# tag/version check (run by `make test-scripts`).
set -uo pipefail
HERE="$(cd "$(dirname "$0")" && pwd)"
pass=0
fail=0
ALL=(APPLE_SIGNING_IDENTITY APPLE_CERTIFICATE_P12_BASE64 APPLE_CERTIFICATE_PASSWORD APPLE_API_KEY_ID APPLE_API_ISSUER APPLE_API_KEY_P8_BASE64)

# run_mode N REF → "<exit> <stdout>" with the first N credentials set, the rest empty.
run_mode() {
  local n="$1" ref="$2" i=0 v envs=() out rc
  for v in "${ALL[@]}"; do
    if [ "$i" -lt "$n" ]; then envs+=("$v=x"); else envs+=("$v="); fi
    i=$((i + 1))
  done
  out="$(env "${envs[@]}" bash "$HERE/release-mode.sh" "$ref" 2>/dev/null)"
  rc=$?
  echo "$rc $out"
}

check_tag() {
  bash "$HERE/release-mode.sh" --check-tag "$1" "$2" >/dev/null 2>&1
  echo $?
}

expect() { # NAME WANT GOT
  if [ "$2" = "$3" ]; then pass=$((pass + 1)); else echo "FAIL: $1 — want '$2', got '$3'"; fail=$((fail + 1)); fi
}

expect "no credentials, local build"       "0 dry-run" "$(run_mode 0 '')"
expect "no credentials, manual run"        "0 dry-run" "$(run_mode 0 refs/heads/main)"
expect "no credentials, rc tag"            "0 dry-run" "$(run_mode 0 refs/tags/v0.1.0-rc.1)"
expect "no credentials, final tag refused" "1 "        "$(run_mode 0 refs/tags/v0.1.0)"
expect "all credentials, final tag"        "0 release" "$(run_mode 6 refs/tags/v0.1.0)"
expect "all credentials, rc tag"           "0 release" "$(run_mode 6 refs/tags/v0.1.0-rc.2)"
expect "partial credentials refused"       "1 "        "$(run_mode 3 refs/tags/v0.1.0-rc.1)"
expect "one credential refused"            "1 "        "$(run_mode 1 '')"

expect "tag equals version"      0 "$(check_tag refs/tags/v0.1.0 0.1.0)"
expect "rc tag equals version"   0 "$(check_tag refs/tags/v0.1.0-rc.3 0.1.0)"
expect "tag differs"             1 "$(check_tag refs/tags/v0.2.0 0.1.0)"
expect "non-rc suffix refused"   1 "$(check_tag refs/tags/v0.1.0-beta 0.1.0)"
expect "dots are literal"        1 "$(check_tag refs/tags/v0x1x0 0.1.0)"
expect "branch ref refused"      1 "$(check_tag refs/heads/main 0.1.0)"

- [ ] **Step 3: Write `scripts/release-mode.sh`**

```bash
#!/usr/bin/env bash
# How a Ubilink build is signed (spec §3 "Safety rules"). Used by `make dist`,
# scripts/bundle-macos.sh and .github/workflows/release.yml.
#   release-mode.sh [GIT_REF]                      print "release" or "dry-run";
#                                                  exit 1 (reason on stderr) = do not build
#   release-mode.sh --check-tag GIT_REF VERSION    exit 0 iff GIT_REF is vVERSION or vVERSION-rc.N
# It can also be sourced for APPLE_VARS / credential_count / resolve_mode / tag_matches_version.

APPLE_VARS=(APPLE_SIGNING_IDENTITY APPLE_CERTIFICATE_P12_BASE64 APPLE_CERTIFICATE_PASSWORD APPLE_API_KEY_ID APPLE_API_ISSUER APPLE_API_KEY_P8_BASE64)

credential_count() {
  local n=0 v
  for v in "${APPLE_VARS[@]}"; do
    if [ -n "${!v:-}" ]; then n=$((n + 1)); fi
  done
  echo "$n"
}

# resolve_mode GIT_REF (e.g. refs/tags/v0.1.0, refs/tags/v0.1.0-rc.1, refs/heads/main, "")
resolve_mode() {
  local ref="${1:-}" n total="${#APPLE_VARS[@]}"
  n="$(credential_count)"
  if [ "$n" -ne 0 ] && [ "$n" -ne "$total" ]; then
    echo "release-mode: partial Apple credentials ($n of $total set); set all of ${APPLE_VARS[*]} or none" >&2
    return 1
  fi
  if [ "$n" -eq "$total" ]; then
    echo release
    return 0
  fi
  case "$ref" in
    refs/tags/v*-*) echo dry-run ;; # pre-release tag: an un-notarized build is allowed
    refs/tags/v*)
      echo "release-mode: $ref is a final release tag but no Apple credentials are set; refusing to build an un-notarized final release" >&2
      return 1
      ;;
    *) echo dry-run ;; # manual run or local build
  esac
}

# tag_matches_version GIT_REF VERSION
tag_matches_version() {
  local ref="$1" ver="$2" tag
  case "$ref" in
    refs/tags/v*) tag="${ref#refs/tags/v}" ;;
    *)
      echo "release-mode: $ref is not a version tag" >&2
      return 1
      ;;
  esac
  if [ "$tag" = "$ver" ]; then return 0; fi
  case "$tag" in
    "$ver"-rc.*)
      local n="${tag#"$ver"-rc.}"
      case "$n" in '' | *[!0-9]*) ;; *) return 0 ;; esac
      ;;
  esac
  echo "release-mode: tag v$tag does not match version $ver (expected v$ver or v$ver-rc.N)" >&2
  return 1
}

if [ "${BASH_SOURCE[0]}" = "$0" ]; then
  set -uo pipefail
  if [ "${1:-}" = "--check-tag" ]; then
    tag_matches_version "${2:?git ref}" "${3:?version}"
  else
    resolve_mode "${1:-}"
  fi
fi
```

- [ ] **Step 3: Replace `scripts/bundle-macos.sh` with:**

```bash
#!/usr/bin/env bash
# Build Ubilink.app — and, for the dist modes, a DMG — with Apple's own tools only
# (no tauri-cli: Tauri embeds the frontend at compile time, so the binary is
# self-contained). Design: docs/superpowers/specs/2026-09-14-v0.1-release-design.md §3.
#
#   bundle-macos.sh dev      host-arch app signed with a stable self-signed identity, so
#                            macOS keeps Accessibility/Automation grants across rebuilds
#                            (what `make bundle` runs)
#   bundle-macos.sh dry-run  universal app + DMG, hardened runtime, ad-hoc signed, named
#                            …-UNNOTARIZED.dmg (`make dist` without Apple credentials)
#   bundle-macos.sh release  universal app + DMG, Developer ID, notarized and stapled
#                            (`make dist` with all six APPLE_* variables — see
#                            docs/RUNBOOK-release.md)
set -euo pipefail

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
MODE="${1:-dev}"
# shellcheck source=scripts/release-mode.sh
. "$ROOT/scripts/release-mode.sh"

APP_NAME="Ubilink"
EXE="ubilink"
BUNDLE_ID="org.dhanesh.ubilink"
VERSION="$(bash "$ROOT/scripts/version.sh")"
ENTITLEMENTS="$ROOT/desktop/Ubilink.entitlements"
SRC_ICON="$ROOT/desktop/icons/icon.png"
OUT="$ROOT/desktop/target/bundle"
APP="$OUT/$APP_NAME.app"
BIN=""
DMG=""
KEYCHAIN=""
WORK="$(mktemp -d)"

log() { echo "[bundle:$MODE] $*" >&2; }
die() { echo "[bundle:$MODE] error: $*" >&2; exit 1; }
cleanup() {
  if [ -n "$KEYCHAIN" ]; then security delete-keychain "$KEYCHAIN" 2>/dev/null || true; fi
  rm -rf "$WORK"
}
trap cleanup EXIT

case "$MODE" in
  dev | dry-run) ;;
  release)
    n="$(credential_count)"
    [ "$n" -eq "${#APPLE_VARS[@]}" ] ||
      die "release mode needs all ${#APPLE_VARS[@]} APPLE_* variables ($n set) — see docs/RUNBOOK-release.md"
    ;;
  *) die "unknown mode '$MODE' (expected dev, dry-run or release)" ;;
esac

build_binary() {
  if [ "$MODE" = dev ]; then
    log "building the release binary for this Mac…"
    cargo build --release --manifest-path "$ROOT/desktop/Cargo.toml"
    BIN="$ROOT/desktop/target/release/$EXE"
  else
    local t
    for t in aarch64-apple-darwin x86_64-apple-darwin; do
      log "building for $t…"
      cargo build --release --locked --target "$t" --manifest-path "$ROOT/desktop/Cargo.toml"
    done
    mkdir -p "$OUT"
    BIN="$WORK/$EXE-universal"
    lipo -create -output "$BIN" \
      "$ROOT/desktop/target/aarch64-apple-darwin/release/$EXE" \
      "$ROOT/desktop/target/x86_64-apple-darwin/release/$EXE"
  fi
  [ -x "$BIN" ] || die "binary not found at $BIN"
}

assemble_app() {
  log "assembling $APP_NAME.app $VERSION…"
  [ -f "$SRC_ICON" ] || die "icon source missing: $SRC_ICON"
  rm -rf "$APP"
  mkdir -p "$APP/Contents/MacOS" "$APP/Contents/Resources"
  cp "$BIN" "$APP/Contents/MacOS/$EXE"

  local iconset="$WORK/$APP_NAME.iconset" spec px name
  mkdir -p "$iconset"
  for spec in "16:16x16" "32:16x16@2x" "32:32x32" "64:32x32@2x" \
    "128:128x128" "256:128x128@2x" "256:256x256" "512:256x256@2x" \
    "512:512x512" "1024:512x512@2x"; do
    px="${spec%%:*}"
    name="${spec##*:}"
    sips -z "$px" "$px" "$SRC_ICON" --out "$iconset/icon_${name}.png" >/dev/null
  done
  iconutil -c icns "$iconset" -o "$APP/Contents/Resources/icon.icns"

  cat >"$APP/Contents/Info.plist" <<PLIST
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>CFBundleName</key><string>$APP_NAME</string>
  <key>CFBundleDisplayName</key><string>$APP_NAME</string>
  <key>CFBundleIdentifier</key><string>$BUNDLE_ID</string>
  <key>CFBundleExecutable</key><string>$EXE</string>
  <key>CFBundleIconFile</key><string>icon</string>
  <key>CFBundlePackageType</key><string>APPL</string>
  <key>CFBundleVersion</key><string>$VERSION</string>
  <key>CFBundleShortVersionString</key><string>$VERSION</string>
  <key>LSMinimumSystemVersion</key><string>10.15</string>
  <key>NSHighResolutionCapable</key><true/>
  <!-- Shown on the Automation (Apple Events) prompt when Ubilink scripts another app. -->
  <key>NSAppleEventsUsageDescription</key>
  <string>Ubilink reads the link (URL or file path) of the app you're in, to create a link.</string>
</dict>
</plist>
PLIST
  plutil -lint "$APP/Contents/Info.plist" >/dev/null
}

# A stable self-signed identity for dev builds: macOS keys Accessibility/Automation
# grants to the signing identity, so ad-hoc dev builds would lose them on every
# rebuild. Prints the identity name (or "-" for ad-hoc if it can't be created).
ensure_dev_identity() {
  local id="Ubilink Self-Signed" tmp
  if ! security find-certificate -c "$id" >/dev/null 2>&1; then
    log "creating a one-time self-signed code-signing identity ($id)…"
    tmp="$WORK/dev-identity"
    mkdir -p "$tmp"
    cat >"$tmp/req.cnf" <<CNF
[ req ]
distinguished_name = dn
prompt = no
x509_extensions = v3
[ dn ]
CN = $id
[ v3 ]
keyUsage = critical, digitalSignature
extendedKeyUsage = critical, codeSigning
basicConstraints = critical, CA:false
CNF
    openssl req -x509 -newkey rsa:2048 -nodes -days 3650 \
      -keyout "$tmp/key.pem" -out "$tmp/cert.pem" -config "$tmp/req.cnf" >/dev/null 2>&1
    # -legacy + a throwaway transport password: Apple's `security` rejects OpenSSL 3's
    # default PKCS12 MAC and empty-password p12s.
    openssl pkcs12 -export -legacy -inkey "$tmp/key.pem" -in "$tmp/cert.pem" \
      -name "$id" -out "$tmp/id.p12" -passout pass:ubilink-bundle >/dev/null 2>&1
    security import "$tmp/id.p12" -k "$HOME/Library/Keychains/login.keychain-db" \
      -P "ubilink-bundle" -T /usr/bin/codesign >/dev/null 2>&1
  fi
  if security find-certificate -c "$id" >/dev/null 2>&1; then
    echo "$id"
  else
    log "WARNING: self-signed identity unavailable; signing ad-hoc (grants reset on rebuild)"
    echo "-"
  fi
}

# Import the Developer ID certificate into a temporary keychain that is deleted on exit.
import_developer_id() {
  local kc_pass p12="$WORK/cert.p12"
  KEYCHAIN="$WORK/ubilink-signing.keychain-db"
  kc_pass="$(openssl rand -hex 24)"
  security create-keychain -p "$kc_pass" "$KEYCHAIN"
  security set-keychain-settings -lut 3600 "$KEYCHAIN"
  security unlock-keychain -p "$kc_pass" "$KEYCHAIN"
  printf '%s' "$APPLE_CERTIFICATE_P12_BASE64" | base64 --decode >"$p12"
  security import "$p12" -k "$KEYCHAIN" -P "$APPLE_CERTIFICATE_PASSWORD" -T /usr/bin/codesign >/dev/null
  rm -f "$p12"
  security set-key-partition-list -S apple-tool:,apple: -s -k "$kc_pass" "$KEYCHAIN" >/dev/null
  # Search the temporary keychain first so codesign finds the identity.
  # shellcheck disable=SC2046
  security list-keychains -d user -s "$KEYCHAIN" $(security list-keychains -d user | tr -d '"')
}

sign_app() { # IDENTITY
  local args=(--force --options runtime --entitlements "$ENTITLEMENTS" --sign "$1")
  if [ "$MODE" = release ]; then args+=(--timestamp); fi
  codesign "${args[@]}" "$APP"
}

notarize() { # FILE (a .zip of the app, or the .dmg)
  local key="$WORK/AuthKey_${APPLE_API_KEY_ID}.p8" result status id
  result="$WORK/notary-$(basename "$1").json"
  [ -f "$key" ] || printf '%s' "$APPLE_API_KEY_P8_BASE64" | base64 --decode >"$key"
  log "notarizing $(basename "$1") (waits for Apple)…"
  xcrun notarytool submit "$1" --key "$key" --key-id "$APPLE_API_KEY_ID" \
    --issuer "$APPLE_API_ISSUER" --wait --timeout 30m --output-format json >"$result" || true
  status="$(plutil -extract status raw -o - "$result" 2>/dev/null || echo "unknown")"
  if [ "$status" != "Accepted" ]; then
    id="$(plutil -extract id raw -o - "$result" 2>/dev/null || echo "unknown")"
    xcrun notarytool log "$id" --key "$key" --key-id "$APPLE_API_KEY_ID" --issuer "$APPLE_API_ISSUER" >&2 || true
    die "notarization of $(basename "$1") returned '$status' (submission $id)"
  fi
}

make_dmg() {
  local stage="$WORK/dmg"
  if [ "$MODE" = release ]; then
    DMG="$OUT/$APP_NAME-$VERSION-universal.dmg"
  else
    DMG="$OUT/$APP_NAME-$VERSION-universal-UNNOTARIZED.dmg"
  fi
  log "creating $(basename "$DMG")…"
  mkdir -p "$stage"
  cp -R "$APP" "$stage/"
  ln -s /Applications "$stage/Applications"
  rm -f "$DMG"
  hdiutil create -volname "$APP_NAME" -srcfolder "$stage" -ov -format UDZO "$DMG" >/dev/null
  if [ "$MODE" = release ]; then
    codesign --force --timestamp --sign "$APPLE_SIGNING_IDENTITY" "$DMG"
  else
    codesign --force --sign - "$DMG"
  fi
}

verify_outputs() {
  log "verifying…"
  local exe="$APP/Contents/MacOS/$EXE" archs ents keys plist="$APP/Contents/Info.plist"
  if [ "$MODE" != dev ]; then
    archs="$(lipo -archs "$exe")"
    case " $archs " in *" arm64 "*) ;; *) die "no arm64 slice (have: $archs)" ;; esac
    case " $archs " in *" x86_64 "*) ;; *) die "no x86_64 slice (have: $archs)" ;; esac
  fi
  codesign --verify --deep --strict --verbose=2 "$APP"
  ents="$(codesign -d --entitlements - --xml "$APP" 2>/dev/null)"
  keys="$(printf '%s' "$ents" | grep -o '<key>[^<]*</key>' || true)"
  [ "$keys" = "<key>com.apple.security.automation.apple-events</key>" ] ||
    die "entitlements must be exactly the Apple Events entitlement, got: ${keys:-none}"
  [ "$(plutil -extract CFBundleShortVersionString raw -o - "$plist")" = "$VERSION" ] ||
    die "Info.plist version is not $VERSION"
  plutil -extract NSAppleEventsUsageDescription raw -o - "$plist" >/dev/null ||
    die "Info.plist has no NSAppleEventsUsageDescription"
  if [ -n "$DMG" ]; then hdiutil verify "$DMG" >/dev/null; fi
  if [ "$MODE" = release ]; then
    spctl -a -t exec -vv "$APP"
    xcrun stapler validate "$APP"
    xcrun stapler validate "$DMG"
  fi
}

build_binary
assemble_app
case "$MODE" in
  dev) sign_app "$(ensure_dev_identity)" ;;
  dry-run) sign_app - ;;
  release)
    import_developer_id
    sign_app "$APPLE_SIGNING_IDENTITY"
    ditto -c -k --keepParent "$APP" "$WORK/$APP_NAME.zip"
    notarize "$WORK/$APP_NAME.zip"
    xcrun stapler staple "$APP"
    ;;
esac
if [ "$MODE" != dev ]; then make_dmg; fi
if [ "$MODE" = release ]; then
  notarize "$DMG"
  xcrun stapler staple "$DMG"
fi
verify_outputs
log "done: $APP${DMG:+ and $DMG}"
if [ "$MODE" = dev ]; then
  log "grant Accessibility + Automation to THIS app once (or use the in-app onboarding)."
fi
```

# Release pipeline (spec §4; runbook: docs/RUNBOOK-release.md).
#   verify ─┬─ build-app ─────────┬─ draft-release   (tags only)
#           └─ sign-integrations ─┘
# - A tag must equal the app version (desktop/Cargo.toml): vX.Y.Z or vX.Y.Z-rc.N.
# - build-app is notarized when all six APPLE_* secrets exist in the `release`
#   environment; an rc tag or a manual run may produce an UNNOTARIZED dry-run DMG; a
#   final tag without credentials FAILS (scripts/release-mode.sh).
# - The release is only ever a DRAFT; a maintainer publishes it after the RC checklist.
# - Least privilege: everything is `contents: read` except draft-release. Every
#   `uses:` is pinned to a commit SHA (same pins as ci.yml). No build cache in the
#   signing jobs, so a poisoned cache can't reach a signer.
name: release

on:
  push:
    tags: ["v*"]
  workflow_dispatch: {}

concurrency:
  group: release-${{ github.ref }}
  cancel-in-progress: false

permissions:
  contents: read

jobs:
  verify:
    if: >-
      (github.event_name == 'push' && startsWith(github.ref, 'refs/tags/v')) ||
      (github.event_name == 'workflow_dispatch' && github.ref == 'refs/heads/main')
    runs-on: macos-latest
    timeout-minutes: 90
    outputs:
      version: ${{ steps.version.outputs.version }}
    steps:
      - uses: actions/checkout@11d5960a326750d5838078e36cf38b85af677262 # v4.4.0
        with:
          persist-credentials: false

      - name: Install pinned Rust + rustfmt + clippy
        uses: dtolnay/rust-toolchain@02cb101ec7c40f2c49e1d9714d64511d8e1b74de # master @ 2026-09-12
        with:
          toolchain: "1.92.0"
